# Gym Club Analysis

Analysis of gym memberships and attendance using Python (pandas), Jupyter Notebook, and Power BI.

## Project files

- `data/raw/`: four original CSV datasets, unchanged.
- `data/processed/`: CSV outputs generated by the supplied notebook.
- `notebooks/gym_club_analysis.ipynb`: data profiling, validation, and attendance filtering.
- `dashboard/Gym_Club_Analysis.pbix`: supplied Power BI dashboard.

## Data preparation

The notebook checks missing values, duplicates, dates, membership plans, and user/gym references. It calculates ages for comparison and session durations. Attendance before signup is excluded from the exported attendance table. The users export retains the original recorded ages; calculated ages are diagnostic only.

## Run the notebook

Install dependencies with `pip install -r requirements.txt`, launch Jupyter, open the notebook from the `notebooks` folder, and run all cells. Outputs are saved to `data/processed`.

## Power BI

Open the PBIX file in Power BI Desktop. To refresh on another computer, update its data source paths to the relevant local CSV files. The supplied dashboard has not been modified or refreshed as part of packaging.

## Data source

Original datasets supplied with this project. Confirm the original source license and attribution requirements before redistributing the datasets.
